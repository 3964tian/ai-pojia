# 内置提示词

`ai-pojia.md` 从 gpt-instruct v45 改写，随仓库提供，安装时不从网络下载。

改写保留任务连续执行、修改副本、工件交付、基线对照和恢复验证；加入对明确授权任务的误拒纠正。原版自动将所有目标当成合成环境、忽略归属/范围、强制禁止任何拒答的条款，以及无关的生物和叙事分支未保留。

`python3 install.py` 将 Codex 顶层 `model_instructions_file` 指向受管提示词副本。该设置替换内置工作指令；`python3 install.py --uninstall` 恢复原指令设置。

`source.json` 记录固定上游、实际包内文件名、原始摘要及改写版摘要。加载机制与模型效果分开验证；当前没有通用取消拒答或正式 DEMO 通关的实测结论。
